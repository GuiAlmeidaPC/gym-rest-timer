## Full description

Gym Rest Timer keeps your workouts moving with a simple set tracker, rest countdown, and stopwatch built for focused training.

Choose a rest profile, start your workout, finish each set, and let the app track your rest period. The foreground notification and Android Picture-in-Picture support keep the timer visible and controllable while you use other apps.

Features:

- Rest profiles for common training styles
- Set tracking with a clear Finish set action
- Rest countdown with pause, resume, +30 seconds, and skip controls
- Reset sets during an active workout
- Stopwatch with laps
- Foreground notification controls
- Native Android Picture-in-Picture display
- Offline-first: no account, no cloud sync, no ads

Gym Rest Timer is designed to be boring and reliable: open it, pick a rest profile, train, and keep your pace.
