# Gym Rest Timer

Android app implementing [SPEC.md](SPEC.md). Standalone, offline-first, foreground-service backed rest timer with a draggable system overlay. Theme: black background, orange (`#FF6A00`) accents.

## Open & build

1. Open the root directory in Android Studio (Iguana+ / AGP 8.5).
2. Let Gradle sync — it'll fetch Compose BOM, Hilt, Room, KSP.
3. Run on a physical device (overlay + foreground service behavior is awkward to verify in emulators).

## What's intentionally missing

These need to be added before a release build:

| Item | Why missing | How to add |
|---|---|---|
| `gradle/wrapper/gradle-wrapper.jar` | binary | Run `gradle wrapper --gradle-version 8.9` once with a local Gradle install, or copy from another project |
| `gradle/wrapper/gradle-wrapper.properties` | trivial | Generated by the above command |
| `gradlew`, `gradlew.bat` | generated | Same |
| App icon PNG fallbacks (`mipmap-mdpi/...png` etc.) | binary | Right-click `res/` → New → Image Asset in Android Studio; the adaptive vector in `mipmap-anydpi-v26/` covers API 26+ |
| Completion sound asset | binary | Service currently uses `ToneGenerator` for the end-of-rest chime so no asset needed; if you want a custom sample, drop it in `res/raw/` and swap `playCompletionTone()` to `MediaPlayer` |

## Runtime notes

- On first start, request **overlay permission** (system settings deep-link) and **notification permission** (Android 13+ runtime dialog). The dashboard surfaces both as cards if missing.
- The foreground service uses type `specialUse` (no other Android 14 type fits a user-rest timer). Play Store submissions need the property tag justification already in the manifest.
- The tick loop uses `SystemClock.elapsedRealtime()` for drift correction — `delay(1000)` alone accumulates skew over long rests.
- Overlay drag updates `WindowManager.LayoutParams.x/y` directly; the composable observes the same `StateFlow` as the activity, so they stay in sync.

## v1 scope (per SPEC)

In: single rest profile selection, set tracking, pause/resume/+30s/skip, system overlay, foreground notification with actions.
Out: workout history, multi-exercise programs, cloud sync, wearable companion.
